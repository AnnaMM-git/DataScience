Задача бинарной классификации на примере датасета Титаник: https://www.kaggle.com/c/titanic/data

**Цели работы:** 
- Научиться проводить минимальный первичный анализ данных (матрица корреляций, анализ пропусков, другие графики для визуализации данных).
- Построить свою простую модель для бинарной классификации на основе конструкции if-else.
- Познакомиться с такими бейзлайн моделями как: KNN, LogRegression.
- Узнать о важности стандартизации вещественных признаком перед началом предсказаний. 

**Этапы работы:**
1. Подготовка данных
- Анализ кол-ва пропусков в данных
- Поскольку это первая работа по бинарной классификации, то здесь выбрана самая простая стратегия - удалить данные содержащие пропуски
2. Исследование данных с помощью построения различных графиков: scaterplot, bar, piechart
3. Обучение простейшей модели - классификация логическими правилами 
4. Классификация с помощью KNN (так как дотаяет маленький и позволяет это)
5. Важность стандартизации данных (MinMaxScaler, StandardScaler)
6. Fine-tuning гиперпараметра k - кол-ва соседей в KNN
7. Сравнение KNN с логистической регрессией по качеству
